# Munch Match

A 2000s magazine-style yes/no quiz that helps a group of friends decide lunch: what time, go out or order Grubhub, and restaurant or grocery store. Each "no" leads to a different question than "yes". When you finish it says **OK ALL DONE!**, and the **★ Admin** button combines everyone's answers into one plan with a catchy name.

Live version (saves answers for the group): https://claude.ai/artifact/CdyxQEezWPno3LNXmgnXDH

The GitHub Pages version saves answers to Firebase: https://qwerty-ally.github.io/munch-match/
